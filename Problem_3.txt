Problem 3 – Outlier Detection for Gearbox Readings
===================================================

Script: problem_3_gearbox.py
Dataset: gearbox/ directory — 109 CSV files, ~14.5M rows, 3 sensor columns (no header)

How to run (IRIS cluster):
--------------------------
spark-submit problem3_kmeans_gearbox.py \
  --data_path "/path/to/gearbox/*.csv" \
  --k_min 2 --k_max 12 \
  --top_outliers 25 \
  --output_dir ./output_p3

Observations:

  - Nature of outliers (high/low sensor values):

  **

The sensors have means `[0.022, 0.001, 2.401]`. Two distinct outlier types appear consistently across all k values:

**Type A** — high sensor 2 + high sensor 3:
```
[0.015717,  0.375980, 4.941400]   sensor 2 ≈ 38× its mean, sensor 3 near max
[0.002899, -0.362850, 4.928000]
[0.046387,  0.292970, 4.931600]
```
Sensors 2 and 3 simultaneously spike — likely a resonance or shock event.

**Type B** — high sensor 1 + near-zero sensor 3:
```
[0.325780, -0.042419, 0.056152]   sensor 1 ≈ 15× its mean, sensor 3 collapses
[0.301360, -0.042725, 0.053711]
[0.298160, -0.033112, 0.048828]
```
Sensor 1 spikes while sensor 3 drops to near zero — opposite pattern from Type A, suggesting a different fault mode.

Both types persist regardless of k, meaning they are genuinely anomalous operating points rather than artifacts of the clustering.
